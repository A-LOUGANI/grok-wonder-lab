# Contribution Patterns Reference

## Healthy Project Signals
- Recent commits from more than one person
- Issues that receive replies within days, not months
- PRs that are reviewed rather than auto-merged or ignored
- Clear CODE_OF_CONDUCT and CONTRIBUTING files that feel written by humans

## Red Flags
- Single maintainer who has not responded in 6+ months
- Hundreds of open issues with zero activity
- "Good first issue" labels that are years old
- Aggressive bot comments with no human follow-up

## Elegant Contribution Styles

### The Quiet Fix
A one-line correction or documentation improvement that removes friction for future contributors.

### The Architectural Note
A carefully written issue that names a real design tension without demanding a rewrite.

### The Companion Tool
A small script or skill that lives *alongside* the project rather than inside it — often the highest leverage contribution.
